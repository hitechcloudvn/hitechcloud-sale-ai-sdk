# Tài liệu HiTechCloud Sale AI SDK

> [English](README.md) | **Tiếng Việt**

---

Bộ SDK đa ngôn ngữ cho **HiTechCloud Sale AI** — nền tảng chatbot bán hàng &
tự động hoá hội thoại đa kênh.

| Trang | Nội dung |
|-------|----------|
| [getting-started.md](getting-started.vi.md) | Cài đặt và gọi API đầu tiên |
| [authentication.md](authentication.vi.md) | Access token & page access token |
| [api-reference.md](api-reference.vi.md) | Danh mục tài nguyên và endpoint |
| [error-handling.md](error-handling.vi.md) | Mã lỗi và cách xử lý |
| [rate-limiting.md](rate-limiting.vi.md) | Phân trang & giới hạn tốc độ |

- Host production: `https://sale-ai.hitechcloud.vn`
- Host sandbox: `https://sale-ai-sandbox.hitechcloud.vn`
- Base path: `/api/v1`
- Webhook signature header: `X-SaleAI-Signature` (HMAC-SHA256)
